# Spoutin PKI & OpenBao SSH CA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform `spoutin-pki` into a unified PKI platform named `pki` with an OpenBao-backed OpenSSH Certificate Authority, branded web interface (Wi-Fi + SSH), and cold-turkey Debian/systemd migration.

**Architecture:** Refactor the codebase from `services/wifi_enrollment` to `services/pki` with modular domain routers (`routers/wifi.py`, `routers/ssh.py`, `routers/admin.py`), extend OpenBao client with SSH CA public key fetching and OpenSSH certificate signing, expand SQLite schema for SSH requests and certificates, update Web UI with tabbed guest portal and SSH admin dashboard, and update Debian packaging for `pki` cold-turkey migration.

**Tech Stack:** Python 3.11+, FastAPI, Uvicorn, OpenBao REST API (AppRole auth), SQLite3, Slack Bolt (Socket Mode), OpenSSH (`ssh-keygen`), Debian packaging (`dpkg-deb`, systemd).

**Spec:** `docs/superpowers/specs/2026-10-05-pki-ssh-ca-design.md`

## Global Constraints
- Target package name: `pki`
- Target systemd service: `pki.service`
- Target config path: `/etc/pki/config.env`
- Target database path: `/opt/pki/data/inventory.db`
- Cold-turkey migration: No symlinks, no systemd aliases; purge `wifi-enrollment` cleanly
- Default SSH user validity: 8 years (`70080h`)
- Admin principals: `ablack,root,operator`
- Generic account principal: `operator`
- CA key algorithm: `ed25519`
- All tests must pass with `uv run pytest`

```python
    def get_ssh_ca_public_key(self, ssh_mount: str = "ssh") -> str:
        """Fetches the OpenSSH CA public key from OpenBao."""
        token = self._ensure_token()
        url = f"{self.base_url}/v1/{ssh_mount}/config/ca"
        resp = self.session.get(url, headers={"X-Vault-Token": token}, timeout=10)
        resp.raise_for_status()
        data = resp.json().get("data", {})
        pub_key = data.get("public_key")
        if not pub_key:
            raise RuntimeError(f"No public_key returned from {url}")
        return pub_key.strip()

    def sign_ssh_public_key(
        self,
        public_key: str,
        key_id: str,
        principals: list[str],
        ttl: str = "70080h",
        role: str = "admin-user",
        ssh_mount: str = "ssh",
    ) -> dict[str, Any]:
        """Signs an OpenSSH public key with OpenBao SSH secrets engine."""
        token = self._ensure_token()
        url = f"{self.base_url}/v1/{ssh_mount}/sign/{role}"
        payload = {
            "public_key": public_key.strip(),
            "key_id": key_id.strip(),
            "valid_principals": ",".join(p.strip() for p in principals if p.strip()),
            "ttl": ttl.strip(),
        }
        resp = self.session.post(url, headers={"X-Vault-Token": token}, json=payload, timeout=15)
        resp.raise_for_status()
        data = resp.json().get("data", {})
        if not data.get("signed_key"):
            raise RuntimeError(f"No signed_key returned in OpenBao response: {resp.text}")
        return data
```
